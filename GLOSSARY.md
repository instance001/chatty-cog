## chatty-cog
| Term | Alternate term(s) | Alt map | External map | Relation to existing terminology | What it is | What it is not | Source |
| --- | --- | --- | --- | --- | --- | --- | --- |
| ChattyCog | chatty-cog, chattycog_gui | ~ | ~ | Offline-first local AI desktop app | Windows desktop GUI for chatting with local GGUF models through a bundled `llama.cpp` runtime, with modules, memory, sandboxing, and optional nearby-peer networking | Not a cloud chatbot; not internet-dependent for normal inference | chatty-cog/docs/README.md; chatty-cog/docs/USER_MANUAL.md |
| Hot Memory | working set, pinned recent items | ~ | ~ | Visible short-term working context | Small user-visible set of recent or pinned items shown beside the main transcript to keep active context close at hand | Not the full archive; not the same as Luke Warm or cold logs | chatty-cog/docs/README.md; chatty-cog/docs/ARCHITECTURE.md |
| Luke Warm memory | lukewarm memory, rolling summary | ~ | ~ | Rolling summary tier | Persisted rolling summary in `memory/lukewarm.txt` used to keep context usable without stuffing the full log back into prompts | Not a verbatim transcript; not a per-module debrief store | chatty-cog/docs/USER_MANUAL.md; chatty-cog/docs/ARCHITECTURE.md |
| Cold logs | cold log, `cold_log.jsonl` | = | ~ | Append-only event log | Long-term append-only JSONL log written by the Bookkeeper for chat/module events, later search, and auditability | Not a small prompt window; not a cloud logging service | chatty-cog/docs/README.md; chatty-cog/docs/ARCHITECTURE.md |
| Bookkeeper | memory helper, logs helper | ~ | ~ | CPU-only memory/logging assistant | Background helper that records cold events, supports semantic and keyword retrieval, writes Luke Warm memory, and stores per-module rundown summaries | Not the chat inference model; not a GPU-heavy feature | chatty-cog/docs/README.md; chatty-cog/docs/USER_MANUAL.md; chatty-cog/docs/ARCHITECTURE.md |
| Department status updates | departments rundown, module rundown | ~ | ~ | Per-module debrief layer | Latest "what happened in this module" summaries written to `memory/departments.md` and `memory/departments.json` for cross-module context | Not the raw module state itself; not the full log history | chatty-cog/docs/USER_MANUAL.md; chatty-cog/docs/ARCHITECTURE.md |
| Module | department | ~ | ~ | Drop-in extension system | Folder under `modules/` with a `manifest.json` that ChattyCog can scan and open as a closable tab with its own workspace and optional hosted UI | Not just a chat prompt preset; not required to be built into core UI | chatty-cog/docs/MODULES.md; chatty-cog/docs/USER_MANUAL.md |
| Visual load | hosted UI load, `visual_load.json` | = | ~ | Hosted module surface descriptor | Companion module file that advertises a standalone native or web UI ChattyCog can dock inside the module tab | Not a generic config file for every module; not required for discovery | chatty-cog/docs/MODULES.md; chatty-cog/docs/USER_MANUAL.md |
| ChattyCog bridge | module bridge | ~ | ~ | Host-to-module handoff surface | The host-side bridge layer that carries module status, shared state, log-source hints, and optional hosted-UI glue without turning the module into a ChattyCog-owned runtime | Not a full remote plugin protocol; not the module's business logic itself | chatty-cog/docs/MODULES.md; chatty-cog/docs/MODULE_BRIDGE.md; chatty-cog/docs/USER_MANUAL.md |
| Chatty_Sandbox | sandbox | ~ | ~ | Scoped file-work area | Safe scratch folder that the user and orchestrator can browse/edit, with AI-requested file actions limited to approved markdown/text work inside that boundary | Not unrestricted filesystem access; not for arbitrary executables or code generation writes | chatty-cog/docs/README.md; chatty-cog/docs/USER_MANUAL.md; chatty-cog/docs/ARCHITECTURE.md |
| Sandbox task mode | create file mode, edit file mode | ~ | ~ | Deterministic sandbox-turn wrapper | Explicit chat-composer mode that marks a turn as a file task and steers the model toward structured sandbox JSON rather than relying on vague freeform intent detection | Not normal conversation mode; not an auto-approved write path | chatty-cog/docs/README.md; chatty-cog/docs/USER_MANUAL.md |
| Sandbox preload | `sandbox.preload` | = | ~ | Context-gathering sandbox tool | Tool lane that gathers scratchpad, ledger, and likely relevant sandbox files before a longer file task continues | Not a write action by itself; not general filesystem indexing | chatty-cog/docs/USER_MANUAL.md; chatty-cog/docs/ARCHITECTURE.md |
| Task ledger | sandbox ledger, `task_ledger.md` | = | ~ | Structured task-record layer | Durable structured notes file inside the sandbox scratchpad area used to keep current task, next step, questions, and touched files explicit | Not the freeform scratchpad; not the cold log | chatty-cog/docs/ARCHITECTURE.md; chatty-cog/docs/USER_MANUAL.md |
| Capsule library | capsule | ~ | ~ | Saved persona / behavior injection library | Preferences feature for storing named style or behavior overlays that can be layered into the orchestrator system prompt | Not model fine-tuning; not internet-hosted profiles | chatty-cog/docs/README.md; chatty-cog/docs/ARCHITECTURE.md |
| Workflow bundle | generic workflow bundle | ~ | ~ | Whole-app setup sharing lane | Local networking payload used to share a broader ChattyCog setup between nearby peers, separate from module-specific shared state | Not a module bridge payload; not automatic background sync | chatty-cog/docs/README.md; chatty-cog/docs/NETWORKING.md; chatty-cog/docs/USER_MANUAL.md |
| Shared workflow | module shared state | ~ | ~ | Module-specific networking lane | Local networking path for sending one module's exported state through the module bridge without turning that module into a ChattyCog-managed runtime | Not the generic bundle lane; not a global app settings sync | chatty-cog/docs/NETWORKING.md; chatty-cog/docs/USER_MANUAL.md |
